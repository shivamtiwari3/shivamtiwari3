## How I Work

- **Model choice is a P&L decision.** Run evals before every swap, or you're guessing.
- **Design the escalation path before launch,** not after the first angry customer.
- **Prototype in days with agents,** then decide if it deserves a roadmap.
- **Write the spec in public** when the thinking is the product.
